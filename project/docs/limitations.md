# Limitations and delivery status

**Implemented and executed:** a measured 412-cell MANC VNC motor subgraph, rate
dynamics, synthetic input relay, six-leg reduced torque/contact body, 768 registered
trials, 15 variants, all-seed statistics, regional anatomical 3D view, neuron/path
inspection, replay and synthetic videos, and a complete feasibility manuscript.

**Not implemented/established:** reconstructed brain computation; a measured
brain-VNC bridge; exact neuronal arbor mapping; learned primitives or plasticity;
training/adaptation efficiency; a trained matched RNN; biological timing inference;
free-body NeuroMechFly locomotion; robust six-leg motor coordination; measured
muscle mapping; multiple biological connectomes; calibrated physical units; spike
timing; convincing feedback benefit; connectome superiority for key execution.

**Awaiting external inputs or release decisions:** authorized local song files,
source-export license clarification, author/affiliation metadata, public repository
destination and archival DOI deposit. The named copyrighted-song videos are absent.

**Numerical/statistical limits:** eight parameter seeds, three reused sequence
identities, one connectome, model-only bootstrap CIs, exploratory paired tests,
untrained baselines, 2 ms Euler integration with measurable timestep sensitivity,
and within-step state/contact staggering. Contact timing error is conditional on
matched hits; missing values are not zero. The high-level sequencer provides exact
target times and spatial goals to the body decoder.

The original mission is incomplete; the report is not ready for journal submission.
Negative or null findings must remain in any future paper revision.
