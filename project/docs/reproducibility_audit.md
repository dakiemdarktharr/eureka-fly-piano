
The core command is the clean-environment smoke/reproduction test. The all command

## Limits and remaining gates

This is a same-host, separate-environment check, not an independent laboratory
replication. Docker, Linux, another CPU/BLAS, GPU and byte-identical cross-platform
video output were not tested. ffmpeg and fonts can alter video bytes without
altering scientific telemetry. Timestep sensitivity is documented separately and
does not establish high-precision numerical convergence.

Input download rights, the exact upstream neuPrint release, public redistribution
licensing, authorship, public repository and DOI remain unresolved. Authorized
media for `piano_merry_go_round.mp4` and `piano_in_the_pool.mp4` were not supplied;
those artifacts are absent. Brain reconstruction, learned primitive memory,
trained matched baselines and a calibrated biological body remain unimplemented.
The manuscript is an honest exploratory report and is not submission-ready.

The artifact inventory is `artifact_manifest.json`. Raw simulation outputs are
retained locally under `data/runs`; ignored files are regenerated by the scripts,
not promised as contents of a source-only Git clone.
