# Assumptions and scope

User selected option A: an active motor subgraph, followed by scale-up only if feasible.
No authorized song files were supplied. Only newly generated synthetic note events are used.

The first implementation uses the measured MANC descending-to-VNC graph released with
Pugliese et al.'s CPG preprint. It is not a whole-brain simulation. Brain task relays,
feedback projections, primitive composition and the body decoder are engineered
abstractions, explicitly separated from measured connectivity.

The six-leg body is a reduced dynamical surrogate, not NeuroMechFly. Anatomical assets
are documented MANC points/surfaces; no raster reference was supplied or used as data.
Only modeled quantities appear in activity displays. A rate model does not produce
spike times, so a rate raster must never be labeled as a biological spike raster.

All analyses are computational model tests, not experiments on animals. Seeds sample
parameter uncertainty in one connectome; they are not independent biological specimens.
No song, learning, full-brain, novelty, biological validation, or public-release claim
is justified by the engineering benchmark alone.

Third-party data licenses must be resolved independently of the license for new code.
No public upload, DOI, or successful clean-environment reproduction is assumed.
