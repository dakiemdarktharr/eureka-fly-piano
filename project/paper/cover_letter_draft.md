# Cover letter draft - not for submission in the current state

Dear Editors,

We would like to present an exploratory computational benchmark examining the
distinction between connectome-derived rhythmic dynamics and engineered motor-task
execution in a reduced Drosophila VNC model. The current report includes all 768
registered computational runs and emphasizes negative as well as positive findings.
Tonic-drive motor rhythms depend on the retained CPG circuitry, but key execution
can be dominated by a privileged task decoder and is not improved by the measured
graph relative to several simpler controls.

The contribution is an auditable implementation and a caution about behavioral
attribution, not a new biological CPG discovery, whole-brain simulation, or learned
piano skill. The manuscript cites the prior CPG preprint and recent embodied
connectomic controller work, and explicitly identifies the engineered components.

This letter must not be sent until authorship is established, the experimental
scope is judged sufficient for the intended journal, all data rights are resolved,
and author-generated code/data are deposited publicly with persistent identifiers.
The current local package does not satisfy the journal's public availability
requirements. No statement of exclusive submission or author approval is made.

Sincerely,

Author names and affiliations to be supplied.
