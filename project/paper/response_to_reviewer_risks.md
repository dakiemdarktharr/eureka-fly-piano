# Response-to-reviewer risk checklist

| Likely objection | Evidence/current response | Required next action |
|---|---|---|
| This is not a brain-VNC model | True: zero reconstructed brain neurons | Build and validate the measured upstream bridge |
| The decoder does the task | Supported by the baseline outcomes | Route goal variables through constrained circuitry and capacity-match readouts |
| No learning was tested | True; no trainable parameters | Implement prospective primitive learning and held-out tests |
| The no_memory condition is mislabeled | Alias denotes a reach-primitive lesion | Rename in future protocol; retain historical run IDs |
| Baselines are unfair | RNN is untrained and sequence controller simplistic | Add matched training budgets and optimized baselines |
| Parameter replicates are not animals | True; explicitly labeled | Additional connectome instances/physiology |
| The body is too simplified | True; nondimensional tethered 2R legs | Validated musculoskeletal body and MN-muscle mapping |
| Feedback mechanism is assumed | True; A4 contact metric shows no benefit | Measured afferent graph and stronger causal tests |
| High recall does not imply correct timing | Timing and extra contacts are separately reported | Narrow tolerance sensitivity and sequence-level metrics |
| Anatomy could be misleading | Only region mesh is anatomical; neuron graph schematic | Exact neuron meshes and verified registration |
| Numerical resolution matters | 8.77 to 9.30 Hz across tested steps | More precise integrator and convergence study |
| Publication cannot be reproduced publicly | Only local package exists | Resolve source license, public repository and archive DOI |

Never respond to these objections by inflating scope, excluding unfavorable trials,
calling execution learning, or substituting synthetic media for a named song.
