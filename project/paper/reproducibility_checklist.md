# Reproducibility checklist

- [x] Source artifact commits, download URLs and SHA256 digests.
- [x] Filtering rule, pre/post matrix orientation, stable source neuron IDs.
- [x] Exact Python package lock and ffmpeg executable recorded.
- [x] Evaluation and separate calibration seeds.
- [x] Complete experiment registry and all-run numerical outputs.
- [x] Figure/table/video generation scripts and source data.
- [x] Causal neural lesions, degree-preserving randomization and shortcut controls.
- [x] Missing measurements distinguished from zero-valued measurements.
- [x] Browser replay interaction checks and numerical determinism checks.
- [x] Explicit scope, model/body versions and unsupported-claim list.
- [ ] Exact upstream neuPrint release confirmed by the data authors.
- [ ] Source-export redistribution license resolved.
- [ ] Public code/data repositories and DOI archive.
- [ ] Exact neuron arbors and reconstructed brain activity.
- [ ] Learned primitives, trained matched baselines and independent connectome holdouts.
- [ ] Authorized files for the two requested song demonstrations.

Clean-checkout/environment execution is documented in docs/reproducibility_audit.md;
this checklist does not substitute for that audit's actual results.
