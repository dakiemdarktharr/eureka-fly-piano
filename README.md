# Fly Piano Lab

Vietnamese research app for learning and inspecting a motor readout on a tethered fly simulation. The connectome is frozen; this is **not biological piano learning or a whole-brain digital twin**.

Start with [v3 instructions](project/v3/README_v3.md), [protocol](project/v3/PROTOCOL.md), [Vietnamese manuscript](project/v3/paper/manuscript_final_vi.md) and [reviewer action matrix](project/v3/paper/reviewer_vi.md).

V3 adds resumable CEM training, checkpoint curves, train/validation/test reporting, 3D body/brain replay, a Windows bundle builder and Docker Compose. The first 15-minute exploratory run did **not** reach the 85% goal. Its aggregate evidence is included; private score sequences, audio, connectivity arrays and binary replays are excluded from Git.

Prior versions remain under `project/`. Asset licenses and provenance are in `project/v2/assets/`. Software execution and visualizations do not establish biological validity or publication readiness.
